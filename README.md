# 🗳️ 2026 臺灣縣市長選舉競選行程與造勢活動地圖 (ElectCalendar TW)

> 專為 2026 臺灣地方選舉（縣市長篇）打造的開源、純靜態（Static Web App）資訊地圖平台。

![Taiwan Election Header](https://images.unsplash.com/photo-1540575467063-178a50c2df87?auto=format&fit=crop&q=80&w=1000)

## 📌 專案簡介

本專案旨在提供全臺 22 縣市（直轄市與縣市）百里侯參選人最新公開造勢大會、路口掃街拜票、政見發表會與社群直播情報。透過輕量、無後端依賴的純前端架構，選民能即時掌握感興趣的候選人行程，並一鍵匯入 Google 行事曆或將資訊地圖化。

---

## ✨ 核心特色

1. **22 縣市全面覆蓋**：劃分六都、北臺灣、中臺灣、南臺灣及東臺灣離島選區。
2. **多維度動態篩選**：支援按縣市、政黨黨派、活動類型（造勢晚會/掃街/車掃/座談/直播）及時間範圍進行搜尋與排序。
3. **Leaflet.js 全台造勢熱點地圖**：依政黨色彩標記造勢地點，點擊即可導航與查看詳細資訊。
4. **Google 行事曆與離線收藏**：支援一鍵將活動匯入個人 Google Calendar，並透過 `localStorage` 離線關注行程。
5. **志工與團隊行程通報**：提供前端通報表單，讓競選小編與熱心選民即時分享最新行程。
6. **極致響應式與雙色主題**：支援深色 (Dark) 與淺色 (Light) 模式切換，適應手機與桌面端體驗。
